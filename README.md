# Cucumber (Gherkin) Full Support — VA Edition

Расширение VS Code для работы с `.feature` файлами в проектах на базе **Vanessa Automation**.

VA Edition добавляет к базовой поддержке Gherkin сценариев возможности, которые нужны именно в проектах 1С: автодополнение шагов Vanessa Automation, библиотеку известных шагов внутри VS Code, поддержку `@ExportScenarios`, визуальный редактор таблиц Gherkin и удобные инструменты форматирования.

## Что умеет расширение

- Подсвечивает `.feature` и `.testcase` файлы.
- Подсказывает шаги Vanessa Automation при наборе сценария.
- Поддерживает шаги из `.bsl` библиотек и внешнего JSON-каталога.
- Показывает библиотеку известных шагов VA в боковой панели VS Code.
- Позволяет искать шаги, смотреть описание и вставлять их в сценарий.
- Поддерживает `@ExportScenarios` как вызываемые шаги.
- Умеет включать и отключать отображение экспортируемых сценариев.
- Помогает редактировать и выравнивать таблицы Gherkin.

Боковая панель позволяет работать с каталогом шагов Vanessa Automation без переключения в менеджер тестирования. Шаги сгруппированы по разделам: UI, файлы, переменные, подключение TestClient, взаимодействие с клиентом тестирования и другим категориям.

## Возможности подробнее

### Подсветка синтаксиса

Расширение подсвечивает основные конструкции Gherkin:

- ключевые слова `Функционал`, `Контекст`, `Сценарий`, `Структура сценария`, `Дано`, `Когда`, `Тогда`, `И`, `Но`;
- теги сценариев, например `@tree`, `@ExportScenarios`, `@ЗакрытиеДня`;
- комментарии;
- строки в одинарных и двойных кавычках;
- параметры вида `<Параметр>`;
- таблицы Gherkin вида `| ... |`;
- многострочные блоки.

Поддерживается русскоязычный Gherkin, который чаще всего используется в проектах Vanessa Automation.

---

### Автодополнение шагов

Расширение показывает подсказки шагов при наборе текста в `.feature` файле.

Источники шагов:

1. `.bsl` файлы библиотек Vanessa Automation;
2. JSON-каталог шагов VA;
3. `.feature` файлы с тегом `@ExportScenarios`;
4. локальные шаги проекта.

Поддерживаются:

- подсказки по частичному вводу;
- вставка шага в сценарий;
- описание шага;
- сортировка по релевантности;
- параметры шага как поля для заполнения;
- строгий режим сопоставления ключевых слов Gherkin.

Пример:

```gherkin
Когда Я подключаю клиент тестирования "Этот клиент" из таблицы клиентов тестирования
И я нажимаю на кнопку с именем 'ФормаЗаписать'
Тогда открылось окно 'Документ'
```

### Библиотека известных шагов VA

Библиотека шагов отображается в отдельной панели активности VS Code.

Как использовать:

1. Экспортировать шаги из Vanessa Automation в JSON.
2. В VS Code выполнить команду `VA Библиотека: Загрузить JSON`.
3. Открыть панель **Библиотека известных шагов VA**.
4. Найти нужный шаг через дерево или поиск.
5. Вставить шаг в открытый `.feature` файл.

Возможности панели:

- дерево шагов по группам;
- поиск по названию и описанию;
- вставка шага по клику;
- просмотр подробностей шага;
- обновление библиотеки;
- открытие исходного JSON-файла;
- работа без запуска 1С, если JSON уже экспортирован.

Команды:

| Команда | Назначение |
|---|---|
| `VA Библиотека: Загрузить JSON` | Импортировать JSON-каталог шагов |
| `VA Библиотека: Обновить` | Перечитать загруженные данные |
| `VA Библиотека: Найти шаг` | Найти шаг по тексту |
| `VA Библиотека: Открыть JSON` | Открыть текущий JSON-каталог |
| `VA Библиотека: Вставить шаг` | Вставить выбранный шаг в редактор |
| `VA Библиотека: Открыть описание шага` | Посмотреть подробности выбранного шага |

Подробное руководство по экспорту шагов: [`docs/va-json-export.md`](docs/va-json-export.md).

### `@ExportScenarios`

`@ExportScenarios` позволяет переиспользовать сценарии как шаги.

Например, сценарий:

```gherkin
@ExportScenarios

Функционал: Общие шаги открытия форм

Сценарий: Я открываю карточку договора лизинга
    И я открываю навигационную ссылку "e1cib/list/Справочник.ДоговорыЛизинга"
    И открылось окно "Договоры лизинга"
```

После включения режима экспортов расширение сможет предложить шаг:

```gherkin
И Я открываю карточку договора лизинга
```

Режим включается:

- кнопкой в строке состояния `Export Scenarios: On/Off`;
- командой `Cucumber: Toggle Export Scenarios`.

Что делает режим:

- сканирует `.feature` файлы рабочего пространства;
- находит сценарии с тегом `@ExportScenarios`;
- добавляет их в автодополнение;
- показывает визуальную отметку у вызовов экспортируемых сценариев;
- позволяет быстро перейти к исходному сценарию.

### Визуальный редактор таблиц Gherkin

Редактор таблиц помогает работать с данными в `.feature` файлах без ручного выравнивания.

Как открыть:

1. Поставить курсор на строку таблицы.
2. Нажать правой кнопкой мыши.
3. Выбрать `Gherkin: Редактировать таблицу`.

Или использовать горячую клавишу:

```text
Ctrl+Shift+T
```

Возможности:

- редактирование ячеек в табличном интерфейсе;
- добавление строк;
- добавление колонок;
- удаление строк;
- удаление колонок;
- перемещение строк вверх и вниз;
- перемещение колонок влево и вправо;
- скрытие колонок перед сохранением;
- автоматическое выравнивание таблицы;
- сохранение результата обратно в `.feature` файл.

Пример таблицы:

```gherkin
И я устанавливаю фильтр на список
    | 'Дата' | 'Равно' | 'Начало этого дня' |
```

После форматирования:

```gherkin
И я устанавливаю фильтр на список
    | 'Дата' | 'Равно' | 'Начало этого дня' |
```

---

### Быстрое выравнивание таблицы

Если не нужно открывать визуальный редактор, можно выровнять таблицу сразу в тексте.

Команда:

```text
Gherkin: Выровнять таблицу под курсором
```

Горячая клавиша:

```text
Ctrl+Alt+T
```

Расширение определяет таблицу вокруг курсора, считает максимальную ширину каждой колонки и аккуратно выравнивает строки.

## Установка и запуск

### 1. Установить зависимости

```bash
npm install
```

### 2. Собрать расширение

```bash
npm run compile
```

### 3. Запустить Extension Development Host

Открыть проект в VS Code и нажать:

```text
F5
```

### 4. Проверить работу

Открыть `.feature` файл и проверить:

- подсветку Gherkin;
- автодополнение шагов;
- панель библиотеки VA;
- импорт JSON-каталога;
- режим `Export Scenarios`;
- команды редактирования таблиц.

## Настройки

Основные настройки расширения находятся в `settings.json`.

### Пути к файлам шагов

```json
{
  "cucumberautocomplete.steps": [
    "features/**/*.bsl"
  ]
}
```

### JSON-каталог шагов VA

```json
{
  "cucumberautocomplete.vaStepsJson": [
    "tools/va-step-library.json"
  ]
}
```

### Сканирование `.feature` файлов

```json
{
  "cucumberautocomplete.syncfeatures": "features/**/*.feature"
}
```

### Поддержка `@ExportScenarios`

```json
{
  "cucumberautocomplete.includeExportScenarios": true
}
```

### Умные сниппеты

```json
{
  "cucumberautocomplete.smartSnippets": true
}
```

### Форматирование при наборе

```json
{
  "cucumberautocomplete.onTypeFormat": false
}
```

## Планы развития

Возможные направления развития VA Edition:

- интерактивный запуск текущего шага из VS Code;
- выполнение выделенного диапазона шагов;
- синхронизация с открытой Vanessa Automation в режиме менеджера тестирования;
- debug-like режим с подсветкой текущего шага;
- синхронизация breakpoints между VS Code и Vanessa;
- просмотр `Контекст` и `КонтекстСохраняемый`;
- интеграция с Allure/JUnit результатами;
- улучшение поиска по библиотеке шагов;
- поддержка дополнительных источников шагов.

## Основа проекта

Расширение создано на базе [VSCucumberAutoComplete](https://github.com/alexkrechik/VSCucumberAutoComplete) от Alexander Krechik и адаптировано для использования с [Vanessa Automation](https://github.com/Pr-Mex/vanessa-automation).

VA Edition добавляет:

- поддержку `.bsl` библиотек Vanessa Automation как источников шагов;
- JSON-каталог шагов VA;
- боковую панель библиотеки известных шагов;
- поддержку `@ExportScenarios`;
- визуальные подсказки для экспортируемых сценариев;
- визуальный редактор таблиц Gherkin;
- быстрое выравнивание таблиц;
- адаптацию под русскоязычные проекты на Vanessa Automation.
